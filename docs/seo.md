## Editorial rules

Write headings around real use cases. Link each example to a recipe and exact prompt. Keep dates, counts and rendering status accurate. Add meaningful native-language copy instead of duplicating keywords. Do not add fake ratings, fake reviews, invented stars, hidden keyword blocks or claims that every prompt is tested.
