# Originality and provenance

This is an independent flaq.ai open-source collection. We organize familiar creative tasks into newly written briefs, using original fictional campaigns and newly generated visual examples.

## How this release was made

- Scenario planning used general work categories such as product photography, posters, portraits, education and image editing.
- Prompt wording, fictional briefs, composition decisions, copy and review criteria were composed for this repository. No third-party prompt corpus or image collection was imported.
- 28 images were newly generated from the exact prompts saved under [assets/generation](../assets/generation). All edits use this project’s own preceding outputs. Launch-inspired exercises cite the official scenario source; their prompts and images are newly authored.
- The [manifest](../assets/manifest.json) records each output’s input relationships, dimensions, hash and review notes. The generation tool did not expose the underlying model ID.
- The [customizable studio pack](customizable-studio.md) records the referenced collection and the independently chosen direction for each new brief. No third-party prompt wording or source images were imported.
- Official model documentation is linked for factual API claims. The project is neither affiliated with nor endorsed by OpenAI.

## Contribution standard

Do not submit copied prompts with names removed or light synonym replacements. Write from a real use case with independent creative choices. If a contribution includes third-party material, identify it and retain whatever notice its license requires; otherwise replace it with independently created material before submission.

A fictional brand name is not proof that a name is unused. Generated images can resemble existing work unintentionally. We do not promise copyright clearance, trademark availability, exclusive ownership of every AI-generated element or guaranteed commercial suitability.

Keep provenance metadata where present. Do not remove authorship or origin information to imply that borrowed work was created here. “No extra visible watermark” in a creation brief means avoiding unrequested graphic additions, not stripping provenance from an existing file.

## Reporting a concern

Open an issue with the local recipe ID or image filename, the material in question and a short explanation. Do not include private personal information. Maintainers can review, correct, attribute or remove material as appropriate.
